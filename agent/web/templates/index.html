        What are program files?

        Files that run code when you open them, such as .exe, .msi, .bat, .sh or .app. A harmful one can damage your computer or steal your information, so your PC refuses them by default. Only allow them if you know exactly which files you will send and where they came from.

        Phone still can't connect?

        1. Make sure the phone and this computer are on the same Wi-Fi or network. A guest network often stops devices from seeing each other.
        2. Turn off any VPN on the phone and on this computer, or add the VPN's range to allowed_networks in the settings file.
        3. Open - in the phone's browser. If it shows {"error":"unauthorized"}, the network is fine and only the key is wrong: scan the QR code again. If it doesn't load, something between the phone and this computer is blocking it, usually a firewall or a router setting.
