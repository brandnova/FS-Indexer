        Phone still can't connect?

        1. Make sure the phone and this computer are on the same Wi-Fi or network. A guest network often stops devices from seeing each other.
        2. Turn off any VPN on the phone and on this computer, or add the VPN's range to allowed_networks in the settings file.
        3. Open - in the phone's browser. If it shows {"error":"unauthorized"}, the network is fine and only the token is wrong: scan the QR code again. If it doesn't load, something between the phone and this computer is blocking it, usually a firewall or a router setting.

        Let my phone open and download files

        Off by default, so your phone can only see file names. When it's on, a paired phone can open, preview and save any file the agent lists. Files travel without encryption: use it only on a network you trust.

        Receive files from my phone

        Off by default. When it's on, a paired phone can send files into one drop folder on this computer. Nothing is ever overwritten, and the phone can't put files anywhere else. Files travel without encryption: use a network you trust.
